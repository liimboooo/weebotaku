# animewch

## Episodes

This app does not stream anime episodes or fetch them from an external episodes API.

Episode-related info such as `episodes`, `currentEp`, and `nextEpDate` is stored in the local dataset at [frontend/src/data/animeData.js](frontend/src/data/animeData.js).

If you want live episode data later, this section can be updated to point to a real API source.
